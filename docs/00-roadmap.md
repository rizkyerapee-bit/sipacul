# SiPacul

## Deskripsi

SiPacul (Sistem Pencatatan Akuntansi Usaha Lestari) adalah platform ERP Agribisnis berbasis web yang mengintegrasikan proses budidaya, peternakan, pergudangan, investasi, dan akuntansi dalam satu sistem.

---

## Technology Stack

- Frontend : Next.js
- Backend : ASP.NET Core
- Database : PostgreSQL
- ORM : Entity Framework Core
- Cache : Redis
- Storage : MinIO
- Container : Docker
- Reverse Proxy : Nginx
